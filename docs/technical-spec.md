# README.md — Active Arcade Clone (браузерный аналог)

> Этот файл — техническое задание для LLM-ассистента (Cline + MiniMax). Следуй ему при генерации кода, структуры проекта и игровой логики.

---

## 1. Цель проекта

Создать **веб-приложение** (работает в браузере на ПК и смартфоне), которое повторяет концепцию Active Arcade: пользователь встаёт перед камерой, приложение распознаёт его тело и использует движения как игровой ввод. Никаких джойстиков, носимых устройств или установки из магазинов приложений.

**Ключевые отличия от оригинала:**
- Работает в браузере (не требует публикации в App Store / Google Play, обходит региональные ограничения).
- Полностью бесплатно, без рекламы.
- Минимальный MVP: 1–3 мини-игры, которые можно расширять.

## 3. Технологический стек

| Слой | Технология | Причина |
|---|---|---|
| Распознавание позы | **MediaPipe Pose Landmarker** (`@mediapipe/tasks-vision`) | 33 ключевые точки, работает в браузере, высокая точность |
| Альтернатива (fallback) | TensorFlow.js **MoveNet Lightning** | Быстрее на слабых устройствах |
| UI-фреймворк | **React** (Vite) | Управление состоянием игры, компонентный подход |
| Отрисовка | **HTML5 Canvas 2D** | Видео + скелет + игровые элементы |
| Захват видео | `navigator.mediaDevices.getUserMedia` | Стандартный API |
| Стили | CSS Modules или TailwindCSS | Быстрая вёрстка |
| Сборка | **Vite** | Быстрый dev-сервер, простой билд |

> **Важно:** не использовать серверную часть. Всё работает на клиенте. Это упрощает деплой (GitHub Pages / Vercel / Netlify).

## 5. Функциональные требования (MVP)

### 5.1 Базовый модуль (обязательно)
1. **Запрос камеры.** При старте — кнопка «Включить камеру». Обработать отказ в доступе понятным сообщением.
2. **Распознавание позы.** Запустить MediaPipe Pose Landmarker в режиме `VIDEO`, получать 33 точки на каждом кадре.
3. **Отрисовка.** Видео зеркально отображается на canvas; поверх — скелет (линии между ключевыми точками) и точки.
4. **FPS-счётчик** для отладки (можно скрыть в проде).
5. **Стабильность.** Если камера потеряна — показать ошибку и кнопку перезапуска.

### 5.2 Игровой модуль (минимум 2 игры)

**Игра 1: Reaction (реакция)**
- На экране в случайных местах появляются мишени.
- Игрок должен «коснуться» мишени рукой (любая из кистей — `left_wrist` / `right_wrist` — попадает в радиус мишени).
- Счёт растёт, мишень исчезает, появляется новая. Таймер 30 секунд.

**Игра 2: Squat (приседания)**
- Приложение считает угол в колене (`hip → knee → ankle`).
- Приседание засчитывается, когда угол < 90° и затем возвращается > 160° (гистерезис, чтобы не было двойного счёта).
- Счёт + таймер 60 секунд.

> Обе игры используют один и тот же поток точек — игровая логика подписывается на кадры из `gameLoop`.

### 5.3 HUD
- Текущий счёт, таймер, название игры, кнопка «Стоп».
- Экран результатов после окончания.

## 6. Нефункциональные требования

- **Производительность:** ≥ 20 FPS на среднем смартфоне. Если FPS падает — снизить разрешение видео до 640×480.
- **Приватность:** видео **не покидает устройство**. Никаких запросов на сервер с кадрами.
- **Доступность:** крупные элементы UI, контрастные цвета (играют и дети, и пожилые).
- **Адаптивность:** корректно работает на экранах от 360px ширины.

## 8. Ключевые технические детали для LLM

### 8.1 Индексы ключевых точек MediaPipe Pose (33 точки)
```
0  nose            11 left_shoulder   12 right_shoulder
13 left_elbow      14 right_elbow     15 left_wrist
16 right_wrist     23 left_hip        24 right_hip
25 left_knee       26 right_knee      27 left_ankle
28 right_ankle     31 left_foot_index 32 right_foot_index
```
(полный список — в `utils/constants.js`)

### 8.2 Формула угла между тремя точками
```js
// a, b, c — точки {x, y}
// возвращает угол при вершине b в градусах
function angleBetween(a, b, c) {
  const ab = { x: a.x - b.x, y: a.y - b.y };
  const cb = { x: c.x - b.x, y: c.y - b.y };
  const dot = ab.x * cb.x + ab.y * cb.y;
  const magAB = Math.hypot(ab.x, ab.y);
  const magCB = Math.hypot(cb.x, cb.y);
  const cos = dot / (magAB * magCB + 1e-6);
  return Math.acos(Math.max(-1, Math.min(1, cos))) * 180 / Math.PI;
}
```

### 8.3 Проверка попадания кисти в мишень
```js
function isHandOnTarget(wrist, target, radius = 0.06) {
  // координаты нормализованы 0..1
  return Math.hypot(wrist.x - target.x, wrist.y - target.y) < radius;
}
```

### 8.4 Гистерезис для приседаний
```js
// состояние: 'up' | 'down'
if (state === 'up' && kneeAngle < 90)  state = 'down';
if (state === 'down' && kneeAngle > 160) { state = 'up'; repCount++; }
```

### 8.5 Загрузка модели MediaPipe
```js
import { FilesetResolver, PoseLandmarker } from "@mediapipe/tasks-vision";

const vision = await FilesetResolver.forVisionTasks(
  "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@latest/wasm"
);
const landmarker = await PoseLandmarker.createFromOptions(vision, {
  baseOptions: {
    modelAssetPath: "https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task",
    delegate: "GPU"
  },
  runningMode: "VIDEO",
  numPoses: 1
});
```

### 8.6 Зеркалирование видео
```js
canvasCtx.save();
canvasCtx.scale(-1, 1);
canvasCtx.translate(-canvas.width, 0);
// ... рисуем видео и скелет ...
canvasCtx.restore();
```
> Учтите: при зеркалировании координаты `x` точек нужно инвертировать (`1 - x`) для корректной проверки попаданий.

## 9. Что НЕ делать

- ❌ Не отправлять кадры на сервер.
- ❌ Не использовать тяжёлые 3D-движки (Three.js) на MVP.
- ❌ Не добавлять авторизацию, базу данных, аналитику — это MVP.
- ❌ Не пытаться запустить в фоне (браузер приостановит камеру при сворачивании вкладки).
- ❌ Не забывать про `getUserMedia` только по HTTPS (или `localhost`).

## 10. Критерии готовности MVP

- [ ] Камера включается по кнопке, ошибки обрабатываются.
- [ ] Скелет отрисовывается поверх видео с задержкой < 200 мс.
- [ ] Игра «Reaction»: счёт растёт при попадании кистью в мишень, таймер работает.
- [ ] Игра «Squat»: приседания считаются без двойного счёта, таймер работает.
- [ ] Экран результатов после окончания игры.
- [ ] Работает на десктопе (Chrome) и смартфоне (Android Chrome / iOS Safari).
- [ ] FPS ≥ 20 на среднем смартфоне.
- [ ] Проект собирается `npm run build` без ошибок.
